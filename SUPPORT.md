# Support

## Before Asking for Help

1. Read the [contributor handbook](documentation/README.md), especially [getting started](documentation/getting-started.md) and [operations and troubleshooting](documentation/operations.md).
2. Search [existing issues](https://github.com/thomastran117/E-commerce/issues) for the same symptom.
3. Confirm that the problem still occurs on the current `main` branch with a clean configuration.

## Bugs and Documentation Problems

Use the repository's [issue chooser](https://github.com/thomastran117/E-commerce/issues/new/choose) and select **Bug report**. Include:

- The affected frontend, backend, or infrastructure area
- Exact reproduction steps and expected behavior
- Operating system, browser, Java/Node versions, and run mode
- Relevant logs with credentials, tokens, cookies, and personal data removed
- A minimal example when practical

Documentation gaps can be reported as bugs by selecting **Documentation** as the affected area.

## Feature Requests

Use the [issue chooser](https://github.com/thomastran117/E-commerce/issues/new/choose) and select **Feature request**. Describe the user problem and desired outcome before proposing an implementation.

The [candidate roadmap](documentation/roadmap.md) contains possible directions, not commitments or delivery dates.

## Usage Questions

The project does not currently operate a dedicated real-time support or Q&A channel. Search the handbook and existing issues first. If a question reveals broken behavior or missing documentation, open the appropriate issue with enough detail to reproduce or improve it.

Support is provided by maintainers and contributors as availability permits; no response-time guarantee is offered.

## Security and Conduct

- Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).
- Report sensitive community concerns through the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- The in-application `support@shopwave.com` example address is product configuration, not the repository's maintainer support channel.
